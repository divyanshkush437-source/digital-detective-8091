## Task 4.2: Compiler and interpreter
| Point | Compiler | Interpreter |
|---|---|---|
| Translation / execution | Translates source to another form before execution | Executes code through a runtime, often translating as it runs |
| Typical output | Machine code or intermediate code | Program results, sometimes cached bytecode |
| Example | C compiled with GCC | Python run using CPython |
| Advantage | Optimized ahead-of-time executables | Convenient interactive execution and debugging |

Python typically compiles source into bytecode and the interpreter executes that bytecode, so the categories are not mutually exclusive.
