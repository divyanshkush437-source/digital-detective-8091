# Mission 1 — Know Your Computer

## Task 1.1: IPOS
Example: typing and saving a document.

| Stage | What happens | Component |
|---|---|---|
| Input | I type words | Keyboard |
| Processing | The editor handles keystrokes and formatting | CPU and RAM |
| Output | The text appears on the screen | Display |
| Storage | The document is saved | SSD |

## Task 1.2: Hardware and software
| Item | Hardware/software | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | N/A | Enter text |
| CPU | Hardware | N/A | Execute instructions |
| RAM | Hardware | N/A | Hold active data |
| SSD | Hardware | N/A | Store files |
| Operating system | Software | System | Manage hardware and applications |
| Browser | Software | Application | Access websites |
| Text editor | Software | Application | Write documents and code |
| Antivirus | Software | Utility | Detect harmful software |

Operating-system software manages resources; application software performs user tasks; utility software helps maintain or protect the computer.
