# Mission 8 — Final Report and Submission

## Project overview
This repository contains the Digital Detective independent learning assignment, organized into Missions 0–8. It covers computer basics and IPOS, terminal operations, operating systems, how programs run, number representations, Git collaboration and networking.

## Mission index
- Mission 0: Repository and workspace setup
- Mission 1: Computer fundamentals and IPOS
- Mission 2: Terminal and file management
- Mission 3: Operating systems and permissions
- Mission 4: Compiler/interpreter and Python
- Mission 5: Decimal/binary/hexadecimal converter
- Mission 6: Git branches and Pull Requests
- Mission 7: Networking and DNS
- Mission 8: Final verification and submission
